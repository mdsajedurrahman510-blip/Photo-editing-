# AI Photo Studio Pro — Photo-only Edition

A responsive, single-user photo studio based on the supplied Phase 1 project. The application now removes video functionality and adds working browser-side photo finishing, real print-sheet exports, two-person paired-canvas sizing, batch ZIP export, and an optional Python/OpenCV engine.

## Important capability note

The built-in browser engine is **real, non-generative classical image processing**: adaptive exposure, tone/contrast, mild noise softening, and conservative unsharp masking. It does not reconstruct missing facial detail, perform generative face restoration, isolate clothing, or remove a background by itself. Facial geometry is not warped or regenerated by this built-in path.

The optional Python engine adds CPU-based OpenCV luminance denoising, adaptive exposure, conservative sharpening, approximate Haar face localization, and an optional `rembg` background-removal integration. `rembg` and its model weights are not installed by default. A true Remini-class result cannot be guaranteed on free shared hosting or without suitable model weights and compute.

## 1. Run the web application

Requirements: Node.js 20.9+ and npm.

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

Production build:

```bash
npm run build
npm start
```

## 2. Run the optional Python photo engine

Use Python 3.10 or 3.11. From the project root:

```bash
python -m venv .venv
# Windows PowerShell:
.venv\\Scripts\\Activate.ps1
# macOS/Linux:
source .venv/bin/activate
pip install -r engine/requirements.txt
uvicorn engine.main:app --host 0.0.0.0 --port 8000
```

In `.env.local`, set:

```env
PHOTO_ENGINE_URL=http://127.0.0.1:8000
```

Restart Next.js after changing environment variables. The engine URL is kept server-side and is never read from browser input.

### Optional background removal

Background removal is not bundled because segmentation weights can be large and model licensing/deployment requirements vary. To enable the endpoint, install the optional extra on the Python host:

```bash
pip install "rembg[cpu]>=2.0.60"
```

Then restart the engine. The first use may need to download model weights. If rembg is not installed, the app reports that background removal is unavailable instead of showing a fake result.

## 3. Main features

- **Photo Editor:** multi-file upload, before/after preview, on-device enhancement controls, download, optional engine enhancement, optional background replacement.
- **Two-Person Paired Photo:** create a canvas of an exact width/height in millimetres, at a selected DPI, retaining the entire source frame so both people remain together. `Contain` preserves the complete frame; `Cover` fills the canvas but can crop edges.
- **Passport Studio:** calculate 35×45 mm, 40×50 mm, 2×2 inch, and custom photo sizes; create 4×6 inch or A4 sheets; export the sheet as a high-resolution JPG with JFIF DPI metadata.
- **Batch Processing:** process photos sequentially in the current browser session and download completed JPGs as a ZIP. Processing is intentionally sequential to reduce memory pressure on mobile devices.
- **Background presets:** custom HEX/RGB choices are available. Actual subject segmentation requires the optional Python engine with rembg installed.
- **Privacy:** browser fallback processing stays in the browser. Files are held in memory for the current tab; originals are not overwritten. Do not deploy the unauthenticated Python engine publicly without adding authentication, rate limiting, TLS, and upload controls.

## 4. Mobile and desktop use

The interface is responsive. Open the deployed website in Chrome on Android or a desktop browser. In Chrome, use **⋮ → Add to Home screen** (or **Install app**, if shown) to create a home-screen shortcut. It is still a web application, not a native Android APK.

For mobile stability, process large files sequentially, avoid keeping many huge output previews open, and prefer JPG/WebP under 15–20 MB. Some mobile browsers cannot decode HEIC; convert it to JPG before uploading.

## 5. Online deployment

The frontend is a Next.js application and needs a host that supports Next.js server routes. Deploy the repository through a supported Next.js host (for example, Vercel) rather than publishing it as a static-only site. Configure `PHOTO_ENGINE_URL` only when you have deployed the Python engine separately. A static Pages deployment without a compatible Next.js runtime will not run the `/api/engine/*` proxy routes.

A free frontend plan does not automatically provide a free, always-on GPU server. The browser processing and print tools can work without the Python engine; server-side AI features depend on the external engine host and its resources.

## 7. Privacy and identity limitations

- The non-generative browser engine never performs face swaps, facial reshaping, or face reconstruction.
- The Python engine uses approximate face detection only for gentle local lighting. It is not a biometric identity verifier.
- No algorithm can recover details that were never captured with certainty. Aggressive restoration can change facial appearance, so it is deliberately not enabled in strict mode.
- Two-person paired export retains and resizes the complete source image. It does not automatically split the two people into separate official passport portraits.
- Passport dimensions are geometric print dimensions, not confirmation of compliance with a country's current passport rules. Check the applicable authority's specifications before submission.
